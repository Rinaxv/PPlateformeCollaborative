# CollabSpace — Plateforme collaborative de documents en temps réel

Application web de création, modification et partage de documents
avec collaboration en temps réel.

## Technologies
- Frontend : React, Vite, Tiptap, Yjs, Socket.IO
- Backend : Node.js, Express, Socket.IO, JWT
- Base de données : PostgreSQL

## Installation

### Backend
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

- Frontend : http://localhost:5173
- Backend : http://localhost:5000
