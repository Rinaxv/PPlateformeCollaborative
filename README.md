# CollabSpace - Plateforme collaborative de documents en temps reel

Application web de creation, modification et partage de documents avec collaboration en temps reel.

## Technologies
- Frontend : React, Vite, Tiptap, Yjs, Socket.IO
- Backend : Node.js, Express, Socket.IO, JWT
- Base de donnees : PostgreSQL

## Installation
Backend : cd backend, npm install, copier .env.example vers .env, npm run dev
Frontend : cd frontend, npm install, npm run dev
